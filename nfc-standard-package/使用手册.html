TAP & GO · NFC STANDARD PACK

使用手册
在 GitHub 上改你自己的展项页面

不用装软件、不用写代码，浏览器里跟着点就行。预计 15 分钟。

你会改什么

每个展项对应一个 HTML 页面文件。你要做的事就两件：改文字、换图片音视频。改完点一下保存，等一两分钟，观众手机碰 NFC 标签打开的就是新内容。

先选模板

文件夹里有三套风格不同的模板，挑一套顺眼的，复制一份再改（不要直接在模板原件上改）。三套都内置了音频 / 视频二选一槽位：

模板文件排版风格素材文件夹
一碰即达_标准包.html模板A · 铭牌档案风：暖米纸底、衬线标题、通栏首图压标题、铭牌三格横条assets/模板A
模板B_极简白.html模板B · 卡片信息流：正文拆成一张张圆角卡片上下堆叠，插图夹在卡片之间，信息为纵向条目；纯白浅灰底、无衬线大标题assets/模板B
模板C_深色展厅.html模板C · 侧边目录式：左侧固定编号目录（档案/故事/影像），点击滚动定位，右侧对应正文与图片；近黑深底、钢蓝电光强调assets/模板C
三套模板的文字改法完全一样，排版骨架各不相同；每套都能放音频或视频，二选一即可。

开始前

  1. 登录 GitHub 账号（账号由技术组统一开通）
  2. 打开仓库：waiting-create / nfc_heritage
  3. 进入文件夹 nfc-standard-package
第 1 步 · 改文字

打开 HTML 文件，找到最顶上的 CONFIG 配置块

  1. 在文件夹里点开你选好的模板（如 模板B_极简白.html）
  2. 点文件右上角的 铅笔图标（Edit this file），进入编辑
  3. 往下翻，找到被两行 ★★★ 注释夹起来的 CONFIG 块，长这样：
title: "3号窑炉：一条窑的",
titleAccent: "百年呼吸",
lead: "从 1946 年到 2014 年……",

只改引号 " " 里面的字，引号、冒号、逗号、后面的注释都保留不动。每一行对应页面上的一个位置，对照表如下：

配置项页面位置
kicker首图上最小的一行编号
title大标题第一行
titleAccent大标题第二行（橙色）
subtitle大标题下面一行小字
pk1 / pv1 等中间铭牌三格：标签名和值
sec1Title第一段小标题
lead段落1：开头大段引言（衬线大字）
body1段落2：第二段正文
body2段落3：第三段正文
photoCaption / photoYear插图下面的图注和年份
audioTitle / audioMeta音频标题和来源
videoTitle / videoMeta视频标题和来源
audioIntro媒体段前面的介绍文字
analyticsId访问统计站点 ID（百度统计）；留空则不统计，页面不显示次数

改完拉到页面最下面，点绿色的 Commit changes（提交）按钮，再点弹窗里的 Commit changes 确认。

不要动 CONFIG 块以外的任何代码，那些是页面样式和播放功能，碰坏了页面会显示不正常。
第 2 步 · 换图片

把图片放进你选的那个模板文件夹

图片必须改名为用在哪套模板
首图（横版大场景）hero.jpg仅模板A 用；模板B、C 没有首图位，不用放
插图photo.jpg三套都用：A/B 竖版或方，C 方形
  1. 进入 assets，按你选的模板进对应文件夹：模板A 进 模板A，模板B 进 模板B，模板C 进 模板C
  2. 右上角 Add file → Upload files
  3. 把图片拖进去，文件名改成上面的名字（覆盖原有示例图）
  4. 拉到底部点 Commit changes
手机拍照原图通常 3-5MB，能直接用；超过 10MB 的图先发微信给别人再保存一次，体积就小了。注意：图片要放进对应模板的文件夹，放错文件夹页面会读不到。
第 3 步 · 换音频或视频（二选一，可选）

每套模板都能放音频或视频，自己选一个，不用都放

类型文件名CONFIG 里填哪行
音频（mp3）scene.mp3audioSrc 填路径，videoSrc 填 ""
视频（mp4）scene.mp4videoSrc 填路径，audioSrc 填 ""
都没有——两行都填 ""，整段自动隐藏
  • 文件放进对应模板的素材文件夹（assets/模板A、assets/模板B、assets/模板C）
  • 视频点卡片会在当前页弹出播放层，不用跳转新页面
  • 视频建议控制在 50MB 以内，太长现场加载会慢
第 3.5 步 · 接入访问统计（可选）

访问次数在统计后台看，页面上不显示数字

  1. 打开百度统计 tongji.baidu.com，用百度账号登录，新增网站，填本展项页面的 GitHub Pages 链接
  2. 在后台生成统计脚本，复制站点 ID（hm.baidu.com/hm.js? 后面那串字符）
  3. 打开对应模板 HTML，在 CONFIG 里把 ID 填进 analyticsId 一行
  4. 保存提交，等 1-2 分钟，回到统计后台就能看到访问次数（PV）、人数（UV）和设备来源
不填 analyticsId 就不会加载统计，页面也不出现次数数字。统计只记录访问次数和人数，不收集姓名、手机号等个人信息。
第 4 步 · 看效果

打开展示链接预览

  1. 打开你的展项页面链接（技术组给你，形如 https://waiting-create.github.io/nfc_heritage/...）
  2. GitHub Pages 生效有 1-2 分钟延迟，看不到新内容就按 F5 刷新
  3. 检查：图片对不对、文字改没改成功、音频/视频能不能点开播放

有问题就回到第 1 步再改一遍，保存后刷新查看。

常见问题

Q：我改错了想撤回怎么办？
A：在 HTML 文件页面点 History，可以看到每次提交，点进旧版本 → 右上角三点 → Restore 即可恢复。

Q：图片传上去页面还是旧图？
A：等 1 分钟再刷新；还是旧图就强制刷新（Ctrl+F5）。确认上传时文件名和 CONFIG 里写的完全一致，包括大小写和后缀。

Q：标题里想换行怎么办？
A：不用自己加符号，title 是第一行、titleAccent 是第二行，各写各的就行。

Q：之后想再改内容？
A：重复第 1 步改文字、第 2 步换图即可，链接不变，NFC 标签不用重写。

Q：音频和视频能同时放吗？
A：不能，每套模板里都是二选一。填了视频就隐藏音频卡片，填了音频就隐藏视频卡片，不会两个一起出现。

Q：访问次数在哪里看？页面上怎么没有数字？
A：页面本身不显示访问次数。有人打开页面后，访问记录会送到统计平台后台，在那里看访问次数（PV）、访问人数（UV）和设备来源。要启用统计，先在百度统计后台新增站点、复制站点 ID，填到 CONFIG 的 analyticsId；留空则不加载统计，页面也不出现任何次数数字。
